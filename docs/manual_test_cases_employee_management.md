## Notes on the shared public demo
- The demo (`opensource-demo.orangehrmlive.com`) is used by many people simultaneously worldwide. Employee Ids, employee counts and even previously-created test records (including ones created earlier in this same assignment) can change or disappear between sessions — this is expected and is not a defect in the application under test or in this test suite.
- TC_EMP_05 is a great example: it is not a "bug" in OrangeHRM, but an environment characteristic worth knowing about before writing automation against a shared instance (see `pages/employee_page.py` → `add_employee()` for how the automation handles it).
